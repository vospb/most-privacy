Мост: политика конфиденциальности

Действует с 30 октября 2026 года. Относится к расширению «Мост» для Chrome и Яндекс Браузера и к модулю Моста для macOS.

Что Мост обрабатывает

Профили, которые вы добавили сами: название, адрес и порт сервера, IP сервера, логин, пароль, ключи WireGuard и AmneziaWG, закрытый ключ SSH и его фразу-пароль, отпечаток ключа SSH-сервера.

Профили хранятся на этом Mac одним элементом в Связке ключей macOS. Записывает и читает их локальный модуль Моста. Расширение хранит в браузере только два значения: включён ли Мост и какой профиль был последним.

Что уходит в сеть

  • Трафик вкладок к серверу, который вы выбрали, пока Мост включён.
  • Проверочный запрос к https://example.com/ через этот же сервер, когда вы проверяете связь, и один раз после включения.
  • Запрос ключа SSH-сервера по адресу, который вы ввели, когда вы нажимаете «Получить отпечаток сервера».

Больше Мост никуда не обращается: нет аналитики, телеметрии, проверки обновлений и наших серверов.

Кому передаются данные

Никому. Разработчик данные не получает, третьим лицам они не передаются и не продаются. Страну сервера Мост определяет по встроенной базе DB-IP без сетевых запросов.

Как удалить данные

Удалите профили на странице Моста или элемент «Мост — профили браузера» в программе «Связка ключей». Расширение удаляется из браузера обычным способом, его настройки удалятся вместе с ним.

Мост: privacy policy

Effective October 30, 2026. Covers the Мост extension for Chrome and Yandex Browser and the Мост app for macOS.

What Мост handles

The profiles you add yourself: name, server address and port, server IP, login, password, WireGuard and AmneziaWG keys, SSH private key and its passphrase, SSH server key fingerprint.

Profiles are stored on this Mac as one item in the macOS Keychain, written and read by the local Мост app. The extension keeps only two values in the browser: whether Мост is on and which profile was used last.

What goes over the network

  • Traffic of your tabs to the server you chose, while Мост is on.
  • A test request to https://example.com/ through that server when you check the connection, and once after turning Мост on.
  • A request for the SSH server key at the address you entered, when you press “Get server fingerprint”.

Мост contacts nothing else: no analytics, telemetry, update checks or servers of ours.

Who receives data

Nobody. The developer receives no data; nothing is shared with or sold to third parties. The server country comes from the built-in DB-IP database, without network requests.

Deleting data

Delete profiles on the Мост page, or the “Мост — профили браузера” item in Keychain Access. Removing the extension from the browser removes its settings.
